# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` | Yes |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately using [GitHub Security Advisories](https://github.com/rwbu69/eltoolkitde_rwbu/security/advisories/new). Include steps to reproduce, the affected platform/version, and any relevant logs (with cookies, credentials, and personal data removed).
