# Security Policy

## Supported versions

Only the latest release on the [Releases page](https://github.com/rwbu69/eltoolkitde_rwbu/releases)
is supported with security fixes. Development builds may contain unfinished
changes.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability. Use
GitHub's private vulnerability reporting or a private contact method listed on
the repository owner's GitHub profile. Include:

- affected version, platform, and installation format;
- a clear description of the impact;
- reproducible steps or a minimal proof of concept;
- any relevant logs, without cookies, credentials, or personal data.

Please allow reasonable time for investigation before publicly disclosing the
issue. We will acknowledge valid reports, assess the impact, and coordinate a
fix or mitigation when practical.

## Scope

Reports involving the desktop application, bundled sidecars, update/build
workflow, or repository configuration are in scope. Reports about third-party
services or websites should be reported to their respective maintainers too.
