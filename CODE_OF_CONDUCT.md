# Code of Conduct

We want ElToolkitDeRWBU to be a welcoming and constructive project for
everyone.

## Expected behavior

- Be respectful and assume good faith.
- Give specific, actionable feedback.
- Welcome different perspectives and experience levels.
- Focus discussion on the work, not the person.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information without permission.
- Deliberate disruption, spam, or bad-faith reporting.
- Any conduct that would make a reasonable contributor feel unsafe.

Maintainers may remove comments, close discussions, or restrict participation
when behavior violates this code. Report conduct concerns privately to the
maintainers through GitHub rather than escalating them in a public thread.
